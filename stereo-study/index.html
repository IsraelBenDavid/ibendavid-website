Stereo generation user study

You will see pairs of results (A and B) produced by two different methods for the same scene. Each result is a stereo pair: a left-eye and a right-eye view that together create a 3D impression. Your job is simply to say which of the two you find better. There are no right or wrong answers.

Before you start

Please use a modern browser (Chrome / Firefox / Edge), maximize the window, and if possible dim the room lights a little.

How to view a stereo pair

This is a practice example — try each display mode and the fullscreen button before starting. In the study you can switch modes freely at any time, on every comparison.

Side-by-side
Left-eye and right-eye views next to each other. Good for spotting differences between the two views.
Anaglyph 3D
Both views combined into one red-cyan image. With red-cyan glasses you see real depth.
Wiggle
The two views alternate quickly. Nearby objects jump more than distant ones — depth without glasses.
Right eye only
Only the generated right view. Good for judging image quality and artifacts.

Keyboard: 1–4 switch modes, F fullscreen, Space pause/play videos, click a video to pause it.
